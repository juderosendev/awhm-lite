# AWHM Whitepaper vs AWHM Lite

**The Whitepaper (AWHM):** A full theoretical architecture for giving LLMs persistent memory across sessions. It defines a hierarchical graph-tree structure with 5-dimension strength scoring (recency, frequency, salience, specificity, utility), spreading activation retrieval with lateral inhibition, and a two-stage consolidation pipeline where Stage 1 does symbolic extraction and Stage 2 uses LLM calls for refinement, contradiction resolution, and salience scoring. It's the complete vision — designed to scale to tens of thousands of memories with sophisticated retrieval and offline processing.

**This Project (AWHM Lite):** A practical, working subset of that whitepaper you can actually run today. It strips out everything that requires LLM calls or complex graph traversal — no spreading activation, no salience scoring, no Stage 2 consolidation, no hierarchical index. What's left is a flat memory graph with 2-dimension strength scoring (recency + frequency), regex-based pattern matching, symbolic-only consolidation (spaCy NER + rules), and BM25 + embedding retrieval. It's the foundation layer that works locally with zero API calls, designed to be upgraded toward the full whitepaper spec as usage justifies the complexity.
